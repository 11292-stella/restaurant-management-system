Autenticazione — AuthController
POST /api/Auth/register 200 OK
Registrazione nuovo utente con hashing password (BCrypt) e generazione token JWT.
Request body
{
  "nome": "Mario",
  "cognome": "Rossi",
  "username": "mrossi",
  "email": "mario@test.com",
  "password": "password123"
}
Response (estratto)
{
  "token": "eyJhbGc...",
  "user": {
    "id": 1,
    "username": "mrossi",
    "role": 1
  }
}
✓ Token generato, password non esposta nella risposta
POST /api/Auth/login 200 OK
Login con credenziali corrette.
{ "username": "mrossi", "password": "password123" }
✓ Token JWT valido restituito
POST /api/Auth/login 401 Unauthorized
Login con password errata — verifica gestione errore via GlobalExceptionMiddleware.
{
  "message": "Username o password non corretti.",
  "dataErrore": "2026-09-20T14:12:44Z"
}
✓ Nessun accesso concesso, messaggio d'errore corretto
POST /api/Auth/register 400 Bad Request
Registrazione con username già esistente — verifica vincolo di unicità.
{
  "message": "Username già in uso.",
  "dataErrore": "2026-09-20T14:13:23Z"
}
✓ Duplicato correttamente rifiutato
Protezione endpoint — [Authorize] + JWT Bearer
GET /api/Esempio/test 401 Unauthorized
Chiamata senza token su endpoint protetto da [Authorize].
✓ Accesso bloccato dal middleware JWT Bearer, senza raggiungere il codice del controller
GET /api/Esempio/test 200 OK
Stessa chiamata con Bearer Token valido nell'header Authorization.
{ "message": "Ciao mrossi, il tuo ruolo è USER" }
✓ Claims (username, role) letti correttamente dal token
Dominio ristorante — Categoria / Prodotto / Ordine
POST /api/Categoria 201 Created
Creazione categoria.
{ "nome": "Pizze", "descrizione": "Le nostre pizze" }
POST /api/Prodotto 201 Created
Creazione prodotto collegato alla categoria (FK CategoriaId).
{
  "nome": "Margherita",
  "descrizione": "Pomodoro e mozzarella",
  "prezzo": 6.50,
  "attivo": true,
  "esaurito": false,
  "categoriaId": 1
}
✓ Risolto un bug di ciclo infinito Prodotto↔Categoria in serializzazione JSON (fix: ReferenceHandler.IgnoreCycles)
POST /api/Ordine 201 Created
Creazione ordine con righe — calcolo automatico del totale sul server.
Request body
{
  "cliente": "Mario Rossi",
  "righe": [
    { "prodottoId": 3, "quantita": 2 }
  ]
}
Response (estratto)
{
  "totale": 13.00,
  "statoOrdine": 0,
  "righe": [{
    "quantita": 2,
    "prezzoUnitario": 6.50,
    "prodotto": { "nome": "Margherita" }
  }]
}
✓ Totale = 2 × 6.50 = 13.00 calcolato correttamente lato server
PUT /api/Ordine/1/stato 204 No Content
Aggiornamento stato ordine (enum StatoOrdine) su endpoint dedicato.
2  // PRONTO
DELETE /api/Prodotto/{id} 204 No Content
Eliminazione con cascade delle righe ordine collegate (FK OnDelete(DeleteBehavior.Cascade)).
